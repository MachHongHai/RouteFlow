Tạo và kiểm tra bản sao mới

Mở PowerShell tại thư mục dự án. Đặt tên thư mục mới cho mỗi bản sao.

cd D:\Du-an\RouteFlow
.\scripts\dev.ps1 uv run python scripts/backup_local.py backup --destination D:\RouteFlow-backups\TEN_BAN_SAO_MOI
.\scripts\dev.ps1 uv run python scripts/backup_local.py verify --destination D:\RouteFlow-backups\TEN_BAN_SAO_MOI

Backup tạm dừng API và ingestion. Verify phục hồi thử vào PostgreSQL riêng.
